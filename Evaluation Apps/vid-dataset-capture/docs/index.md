# Video Dataset Caputure Tool

This app was initially written by Claude.ai.

This app captures artifacts from a snapshot of the Cell-Guardian UI.  It saves video frames, metadata, and annotations to a structured dataset format suitable for training machine learning models.

## Motivation

The cell-guardian device is unable to determine the presence of a person in its radar view.  It should be a small issue to train an AI model to detect people in a thermal image.
